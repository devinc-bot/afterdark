# SDD Interview Guide

Use this guide when requirements for a new feature are incomplete.

1. Read `spec/constitution/`, the relevant code, and the roadmap.
2. Ask only the questions required to establish intent, scope, non-goals, affected users, and acceptance scenarios.
3. Create or update the three artifacts in `spec/features/active/<NNN-slug>/`: `spec.md`, `plan.md`, and `tasks.md`.
4. Record unresolved decisions in `spec.md` and do not implement them without confirmation unless the user explicitly authorizes assumptions.
5. Review the artifacts before implementation.

The interview is a tool for resolving uncertainty, not a required multi-turn ceremony. Do not create progress tracking files.
